✦ FAQ Knowledge Studio

An AI-powered FAQ Chatbot developed using Python, Streamlit, Pandas, and RapidFuzz.

Project Features

  • AI-Powered FAQ Question Matching
  • Natural Language Question Search
  • Category-Based FAQ Filtering
  • Confidence Score Prediction
  • Intelligent Question Suggestions
  • Chat History Download
  • Knowledge Base Search and Analytics

Technologies Used

Python | Streamlit | Pandas | RapidFuzz | HTML | CSS
